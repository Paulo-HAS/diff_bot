=========================================================
LEIAME - Execução dos Algoritmos de Navegação
=========================================================

Projeto:
Trabalho prático 1

Workspace ROS:
movimentacao_ws

Package:
diff_bot

=========================================================
1. PRÉ-REQUISITOS
=========================================================

Antes de executar os códigos, certifique-se de possuir:

- Ubuntu com ROS Noetic instalado
- Python 3
- CoppeliaSim
- Dependências ROS instaladas:
    - rospy
    - geometry_msgs
    - nav_msgs
    - sensor_msgs
    - tf

Também é necessário que o simulador CoppeliaSim esteja
aberto com a cena correspondente carregada.


=========================================================
2. COMPILANDO O WORKSPACE
=========================================================

Abra um terminal e execute:

cd ~/movimentacao_ws

catkin_make

Após a compilação:

source devel/setup.bash

=========================================================
3. EXECUTANDO O COPPELIASIM
=========================================================

1. Abra o CoppeliaSim pelo prompt
2. Carregue a cena pioneer_p3dx_sim.ttt

IMPORTANTE:
O simulador deve estar executando antes do lançamento
dos algoritmos.

=========================================================
6. EXECUTANDO OS ALGORITMOS
=========================================================

Parra executar os codigos, o path na linha 12 deve ser o path global  do arquivo class_pioneer.py

Todos os algoritmos são executados utilizando arquivos
.launch presentes na pasta launch do package diff_bot.

---------------------------------------------------------
6.1 Tangent Bug
---------------------------------------------------------

roslaunch diff_bot tangent_bug.launch

Descrição:
Executa o algoritmo de navegação Tangent Bug para
desvio reativo de obstáculos utilizando LaserScan.

---------------------------------------------------------
6.2 Seguimento de Trajetória
---------------------------------------------------------

roslaunch diff_bot path_follower.launch

Descrição:
Executa o controlador de seguimento de trajetória
paramétrica (Lemniscata de Gerono).

---------------------------------------------------------
6.3 Campos Potenciais
---------------------------------------------------------

roslaunch diff_bot potential_bot.launch

Descrição:
Executa o algoritmo de navegação por campos
potenciais artificiais.

---------------------------------------------------------
6.4 Estratégia Híbrida
---------------------------------------------------------

roslaunch diff_bot hybrid.launch

Descrição:
Executa a estratégia híbrida combinando
seguimento de trajetória e campos potenciais.

=========================================================
7. OBSERVAÇÕES
=========================================================

- Todos os scripts foram implementados em Python.
- Os nós ROS utilizam os tópicos:
    /odom
    /cmd_vel
    /hokuyo

- Certifique-se de que os sensores e o robô estejam
corretamente configurados na cena do CoppeliaSim.

- Caso ocorram erros de permissão nos scripts Python:

chmod +x ~/movimentacao_ws/src/diff_bot/scripts/*.py

=========================================================
8. FINALIZAÇÃO
=========================================================

Para encerrar a execução:

- Pressione CTRL+C no terminal do ROS
- Pare a simulação no CoppeliaSim
